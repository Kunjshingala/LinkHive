Cloud delete: when it doesn't finish

Account screen, light theme. Approved behavior: the phone is emptied first, then the cloud part is deleted and retried (at launch, when the internet returns, and on Try again) until it's done. Sync stays off for this account until then. Pick option A or B for where the status and Try again live. Profile and stats above are unchanged.

A Tile-led: the sync tile carries the status and Try again

Same pattern as today's "Sync failed + Retry". The Delete Cloud Data row only shows a short "Not finished" badge; tapping it does the same as Try again.
